## ¿Qué es?

VENTORY Desktop es la aplicación de Windows para usar **VENTORY** sin depender del navegador como ventana principal. Incorpora notificaciones, icono en la bandeja y actualizaciones automáticas cuando hay una nueva versión publicada aquí.

## Características

| | |
|---|---|
| 🌐 | Carga la web oficial de VENTORY en un contenedor WebView2 optimizado |
| 🔔 | Notificaciones del sistema integradas con la plataforma |
| 📌 | Icono en la bandeja: cerrar la ventana no cierra la aplicación |
| ⬆️ | Comprueba actualizaciones desde [GitHub Releases](https://github.com/aeeb-dev/ventory-app/releases) |
| 📦 | Un solo `Ventory.exe`; la primera ejecución instala en tu perfil de usuario |

## Requisitos

- Windows 10 u 11 (64 bits)
- [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) (suele estar ya instalado en Windows actualizado)

## Instalación rápida

1. En [**Releases**](https://github.com/aeeb-dev/ventory-app/releases), descarga **`Ventory.exe`**.
2. Ejecútalo con doble clic.
3. La aplicación se instalará en tu carpeta de usuario y quedará lista para usarse.

> **Cerrar la ventana** minimiza a la bandeja. Para salir por completo: clic derecho en el icono → **Salir**.

## Uso de la bandeja

| Acción | Resultado |
|--------|-----------|
| Doble clic en el icono | Mostrar u ocultar la ventana |
| Clic derecho | Menú (incluye buscar actualizaciones) |
| Cerrar con ✕ | La app sigue en segundo plano |

## Actualizaciones

Si hay una versión nueva en Releases, la app puede avisarte y ofrecerte instalarla desde el menú de la bandeja. No hace falta configuración adicional.
